# Founder Manual Work

## Before queue UI
- Observe real OPD workflow.
- Record serial, no-show, break and late-start behavior.
- Note receptionist interruptions and existing tools.

## Before pilot
- Run a paper queue dry run for several clinic sessions.
- Obtain written clinic permission.
- Select clinic contact.
- Define software-outage fallback.
- Manually verify each participating doctor.
- Record verification source/date/evidence.
- Obtain privacy/legal review before real patient records are used.
- Define retention/deletion/backup policy.

## During pilot
Measure baseline and post-pilot waiting time, prediction-window hit rate, no-show rate, patient satisfaction, doctor satisfaction, staff workload, technical failures, and privacy/security incidents.

Do not claim the product reduces waiting unless pilot evidence supports it.
